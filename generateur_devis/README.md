# Générateur de devis & factures (mini‑projet)

Contenu :
- index.html — interface + preview
- style.css — styles partagés
- app.js — logique JavaScript

Prévisualisation locale :
1. Ouvre `generateur_devis/index.html` dans ton navigateur (double‑clic ou `file://`).
2. Les fichiers sont liés par chemins relatifs (`style.css`, `app.js`) : il suffit d'ouvrir index.html pour que tout fonctionne.

Prévisualisation via GitHub Pages :
1. Dans le dépôt GitHub → Settings → Pages, choisis la source : branche `main` (ou `master`) et dossier `/ (root)`.
2. Enregistre. Après publication (quelques dizaines de secondes) ton mini‑projet sera accessible à :
   `https://BB-ESPCI.github.io/Apps_HTML/generateur_devis/`

Remarques :
- Les chemins sont relatifs pour garantir que GitHub Pages servira correctement les fichiers.
- Si tu veux plusieurs mini‑projets, crée d'autres sous‑dossiers (ex. `generateur_devis/simple/`, `generateur_devis/advanced/`) en respectant la même structure `index.html`, `style.css`, `app.js`.
